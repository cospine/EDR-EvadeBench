# Result Data Dictionary

`outcomes_scored.csv` is the canonical dataset. `FINAL_RESULTS.md`, `CASE_SUMMARIES.md`, `technique_level.csv`, `by_product.csv`, `by_payload.csv`, and `metrics/` are derived views. Do not independently edit the derived labels.

| Field | Meaning |
| --- | --- |
| case_id | Stable repository ID: technique-payload-product-environment |
| technique_id | T0 baseline or selected implementation T1-T22 |
| technique_name | Implementation name from the framework schema |
| layer1 | Collection, Transmission or Detection; empty for T0 |
| layer2 | DET strategy from the schema; empty for T0 |
| payload_family | CobaltStrike, Havoc or AdaptixC2 |
| product | Product ID from the schema; DefenderAV means Antivirus, not MDE |
| environment | Win11Enterprise or Server2025 |
| is_baseline | True for T0; False otherwise |
| level | Final L1-L5 label using the manuscript criteria |
| level_name | Human-readable name of that level |

## Case identifiers

The example `T1-HV-SOPH-W11` denotes T1, Havoc, Sophos, and Windows 11 Enterprise. Identifiers are generated by `framework/common.py` and used throughout the repository.

| Dimension | IDs and short codes |
| --- | --- |
| Payload | CobaltStrike = CS; Havoc = HV; AdaptixC2 = AX |
| Product | Sophos = SOPH; Kaspersky = KASP; Bitdefender = BITD; Elastic = ELAS; Huorong = HUOR; DefenderAV = MDAV |
| Environment | Win11Enterprise = W11; Server2025 = S25 |

## Counting and privacy

Every implementation has 36 cases: three payloads x six products x two environments. The 792 non-baseline cases contribute 132 per product. The 36 AES-protected T0 cases are listed separately and excluded from PSD/BDD. Each row is one final case outcome, not an individual execution or a screenshot count.

Internal workbook row/sheet locators and redundant internal outcome codes are omitted from the public CSV. Original screenshots, full logs, host identifiers and concrete experimental network addresses are not part of the released result data. Blank evidence/validation templates are for evaluators' new experiments; they are not historical author records.
