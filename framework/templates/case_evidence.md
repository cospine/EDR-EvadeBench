# Case Evidence Record — template

One record per case (one technique × one payload family × one product × one
environment). Copy this file, or use the CSV generated by
`python framework/score.py template`, which contains a blank row for each of
the 792 cases.

Every field must cite an artifact. `score.py` refuses to score a case whose
evidence is internally inconsistent, so record what you observed rather than
what you expected.

---

## Identification

| Field | Value |
| :--- | :--- |
| `case_id` | e.g. `T7-CS-SOPH-W11` |
| `technique_id` | e.g. `T7` |
| `payload_family` | CobaltStrike / Havoc / AdaptixC2 |
| `product` | Sophos / Kaspersky / Bitdefender / Elastic / Huorong / DefenderAV |
| `environment` | Win11Enterprise / Server2025 |
| Product version & content level | from the product's About/Console page |
| Date / time (UTC) | |
| Operator | |

## Source 1 — endpoint process and network state

| Field | Value | Evidence |
| :--- | :--- | :--- |
| `process_created` | true / false | e.g. Process Monitor capture, ref |
| `process_terminated_by_product` | true / false | e.g. product protection log, ref |
| Process name / PID | | |
| Outbound connection attempted | yes / no | e.g. TCPView or `netstat` capture, ref |

## Source 2 — C2 server logs

| Field | Value | Evidence |
| :--- | :--- | :--- |
| `c2_beacon_observed` | true / false | listener log excerpt, ref |
| `c2_beacon_latency_s` | seconds from execution to callback | listener log timestamp |
| `commands_sent` | integer | C2 console log |
| `commands_completed` | integer | command output captured in console |
| `session_alive_at_end` | true / false | console state at end of the 5-minute post-command window |

Commands are the paper's set: `whoami`, `ipconfig`, `tasklist`, `upload`.

## Source 3 — product alerts / local protection logs

| Field | Value | Evidence |
| :--- | :--- | :--- |
| `product_alert_observed` | true / false | console alert id / export, ref |
| Alert name(s) & detection surface | | |
| Action taken by the product | blocked / terminated / quarantined / none | |

## Timing

| Window | Observation |
| :--- | :--- |
| Beacon window | up to 60 s |
| Pre-command window | 5 min, no commands issued |
| Post-command window | 5 min after the command set |
